# Integrations

## External Systems
- **Bitcoin Blockchain**: O sistema consome dados de endereços públicos e alvos de quebra-cabeças (puzzles).
- **Filesystem**: Integração profunda para armazenamento de "Trap Tables" de múltiplos GBs.

## Network (Planned/WIP)
- **Fleet Management**: Capacidade futura de sincronizar progresso entre múltiplas máquinas via API REST ou sockets.

## APIs & Protocols
- **CLI-centric**: A interface primária é via linha de comando, permitindo integração com scripts bash e automação.
- **Telemetry**: Relatórios de performance periódicos em formato legível por humanos para monitoramento de throughput.
