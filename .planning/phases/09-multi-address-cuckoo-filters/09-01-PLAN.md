# Plan 09-01: Hardware-Adaptive Cuckoo Filter Integration

## Objective
Implement a high-throughput, hardware-adaptive Cuckoo Filter that scales with CPU capabilities (SIMD, Cache, NUMA) to enable searching millions of addresses with near-zero overhead.

## Proposed Changes

### Core
- Create `core/adaptive_filter.hpp`:
    - Define `CuckooFilterInterface` and specialized templates for different ISA levels.
    - Implement `AdaptiveCuckooFilter` wrapper that uses `system/hardware.cpp` to dispatch to the best kernel.
- Implement SIMD Kernels:
    - `lookup_avx512`: Uses `_mm512_cmpeq_epi16_mask` to check 32 fingerprints at once.
    - `lookup_avx2`: Uses `_mm256_cmpeq_epi16` to check 16 fingerprints.
    - `lookup_sse4`: Uses `_mm_cmpeq_epi16` for 8 fingerprints.
- Implement "Zero-Cost" Hashing:
    - Logic to extract bits from `HASH160` (20 bytes) to populate fingerprints (2 bytes) and indices.

### System
- Update `system/hardware.cpp` if needed to expose more specific cache line info.
- Implement NUMA-aware allocator for the filter memory.

### Engine
- Modify `engine/address.cpp` & `engine/kangaroo.cpp`:
    - Add `--targets-file` loading logic to populate the `AdaptiveCuckooFilter`.
    - Inject filter lookup into the inner loop (vectorized).

## Verification Plan

### Automated Tests
- `tests/test_cuckoo_adaptive.cpp`:
    - Verify correctness of all SIMD kernels against a reference scalar implementation.
    - Test NUMA allocation logic on supported systems.
    - Benchmark hashing overhead (Target: < 2 cycles per element).

### Performance Benchmark
- Load 10M addresses and measure search throughput.
- Target: Keep performance within 95% of 1-target speed for up to 10M addresses on AVX2 hardware.
