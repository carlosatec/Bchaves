# Plan 08-01: Fleet Batching Integration

This plan details the integration of Secp256k1 SIMD kernels into the Kangaroo search engine to enable vectorized parallel search (Fleet Mode).

## Objectives
- Replace serial point addition with SIMD-accelerated batch processing.
- Implement a dispatcher that selects the best SIMD backend at runtime.
- Refactor the Kangaroo hot-loop to process multiple "kangaroos" per thread.

## Proposed Changes

### 1. Kangaroo Engine Refactoring
- Modify `engine/kangaroo.cpp` to include a `process_fleet` function.
- Update `KangarooWorkerState` to hold an array of points instead of a single point.
- Implement batch affine normalization (Montgomery Ladder) to minimize inversions.

### 2. SIMD Dispatcher
- Create a unified interface in `core/secp256k1.hpp` to call the best available `point_add` backend.

### 3. Performance Tuning
- Add prefetch hints for jump table lookups.
- Optimize distinguished point (DP) detection for SIMD registers.

## Verification Plan
- **Automated Tests**: Run `crypto_test` to ensure no regression in search logic.
- **Benchmark**: Compare M/s (Mega-keys per second) before and after integration.
- **Hardware Validation**: Verify performance on SSE2 (Legacy Xeon) and AVX2 (Modern) hardware.

## Waves
- **Wave 1**: Infrastructure refactoring (Worker state and dispatcher).
- **Wave 2**: Batch normalization and hot-loop integration.
- **Wave 3**: Benchmarking and final tuning.
