# Phase 6 Plan: Hardware Detection & Auto Mode

## Objective
Improve hardware detection and auto mode for the Bitcoin performance engine with cross-platform support and ISA-aware optimization.

**Purpose:** Enhance hardware detection to correctly identify CPU features, cache sizes, system memory, and architecture. Improve auto-derive to calculate optimal thread counts, batch sizes, and table sizes based on detected hardware. Enable per-ISA optimized code paths (SSSE3, SSE4, AVX, AVX2, AVX512, NEON).

**Output:** Enhanced `system/hardware.cpp`, new `core/*-sse4.cpp`, `core/*-avx2.cpp`, `core/*-avx512.cpp` files, and `system/cli.cpp` with `--list-hardware` flag.

## Tasks

### Task 1: Enhanced Hardware Detection (All Platforms)
**Files:** `system/hardware.cpp`, `system/types.hpp`

**Implementation:**
1. **CPU Brand String (Windows):** Registry `HARDWARE\DESCRIPTION\SYSTEM\CentralProcessor\0`
2. **CPU Brand String (Linux):** `/proc/cpuinfo` "model name"
3. **L1/L2 Cache Detection:** CPUID Leaf 4 (x86) / sysfs (Linux ARM64)
4. **Physical Core Detection:** `GetLogicalProcessorInformationEx()` (Windows) / topology (Linux)
5. **NUMA Detection:** `GetNumaHighestNodeNumber()` (Windows) / `/sys/devices/system/node/` (Linux)
6. **Memory Bandwidth:** Estimate from channel count via WMI (Windows) / dmidecode (Linux)
7. **ARM64 Features (Linux):** getauxval for NEON, SHA2, AES, PMULL, SVE, SME
8. **x86 Features:** Add SSSE3, SSE4.1, SSE4.2, AVX detection

**New HardwareInfo Fields:**
```cpp
std::string cpu_vendor;       // "GenuineIntel", "AuthenticAMD", "ARM"
std::string cpu_family;       // "Core i7", "Ryzen 7", "Cortex-A78"
std::string cpu_model;        // "9700K", "5800X3D", "A78"
bool is_smt_enabled;         // HyperThreading/SMT status
std::uint32_t memory_channels;
std::uint32_t memory_gen;     // DDR4=4, DDR5=5
```

**Verification:** `build/crypto_test | grep -i hardware`

### Task 2: Per-ISA Code Organization
**Files:** New files in `core/` directory

**Organization:**
```
core/sha256.hpp (base template)
core/sha256-sse4.cpp (SSE4.1/2 implementations)
core/sha256-avx.cpp (AVX 128-bit)
core/sha256-avx2.cpp (AVX2 256-bit)
core/sha256-avx512.cpp (AVX512 512-bit)

core/secp256k1.hpp (base template)
core/secp256k1-sse4.cpp
core/secp256k1-avx2.cpp
core/secp256k1-avx512.cpp
core/secp256k1-arm64.cpp (NEON)

core/ripemd160.hpp (base template)
core/ripemd160-sse4.cpp
core/ripemd160-avx2.cpp
```

**Implementation Pattern:**
- Each file uses `#ifdef` guards for its ISA requirement
- Base header selects best available implementation at compile-time
- Runtime dispatch via function pointers based on detected features

**Example Selection Logic:**
```cpp
// In sha256.hpp
#if defined(__AVX512F__)
    #include "sha256-avx512.cpp"
#elif defined(__AVX2__)
    #include "sha256-avx2.cpp"
#elif defined(__SSE4_1__)
    #include "sha256-sse4.cpp"
#else
    #include "sha256-portable.cpp"
#endif
```

**Verification:** Compile with different `-march=` flags, verify correct implementation selected

### Task 3: ISA-Aware Auto-Tune
**Files:** `system/hardware.cpp`

**Implementation:**
1. **Batch Size by ISA:**
   - SSSE3: base * 1
   - SSE4: base * 2
   - AVX: base * 2
   - AVX2: base * 4
   - AVX512: base * 8
   - NEON: base * 2

2. **Thread Count by Profile + SMT:**
   - safe: physical_cores / 2 (Intel) or / 4 (AMD SMT)
   - balanced: physical_cores
   - max: logical_cores

3. **CPU-Specific Tuning:**
   - Xeon: threads = min(threads, physical), batch *= 2
   - Core i7/i9: batch *= 1.5
   - Ryzen: batch *= 1.5, handle CCX/CCDs
   - Apple Silicon: batch *= 2, threads = efficiency_cores

4. **Verbose Output:**
```
[*] Hardware Report:
    CPU: Intel Core i7-9700K @ 3.60GHz
    Vendor: Intel, Family: Core i7, Model: 9700K
    Cores: 8 (Physical: 8, Logical: 8, SMT: No)
    Cache: L1d=32KB, L2=256KB, L3=12MB
    Memory: 32GB DDR4 (Channels: 2)
    Features: SSSE3, SSE4.1, SSE4.2, AVX2, BMI2, SHA-NI
    ISA Level: AVX2 (256-bit)
    Recommended Tuning:
      Threads: 8, Batch: 2048, Table: 2097152
    [Using AVX2 optimized SHA256, AVX2 secp256k1]
```

**Verification:** `./address targets.txt -b 32 -A balanced --verbose`
