# 🚀 Getting Started

Welcome to **Bchaves**, the high-performance Bitcoin key search engine. This guide will help you set up and run your first search.

## 📥 Installation

### 1. Requirements
- **Compiler**: `g++` (C++17 support) or `clang`.
- **Build System**: `make`.
- **OS**: Windows (via MinGW/MSYS2) or Linux.
- **Hardware**: x86_64 or ARM64 (Apple Silicon, Raspberry Pi 4/5, Oracle Cloud).

### 2. Compilation
Clone the repository and build all modules:
```bash
git clone https://github.com/carlosatec/Bchaves
cd Bchaves
make all
```

### 3. Verification
Verify the cryptographic kernel integrity:
```bash
make test
./build/crypto_test
```

## 🛠️ Your First Search

The most common use case is searching for a specific Bitcoin address within a bit range (Bitcoin Puzzle).

### Example: Searching Puzzle #65
1. Create a file named `targets.txt` with the target address:
   ```text
   13zb1hQbWVsc2S7ZTZnR2G4undNNpdh5so
   ```
2. Run the `address` engine with the recommended hybrid mode:
   ```bash
   ./build/address targets.txt -b 65 -R hybrid -A balanced
   ```

### Command Breakdown:
- `targets.txt`: Path to the file containing target addresses.
- `-b 65`: Bit range for the puzzle.
- `-R hybrid`: Uses the pseudo-random partitioned explorer.
- `-A balanced`: Automatically tunes thread count for your CPU.

## 📊 Understanding Output

While the search is running, you will see a status line:
`[65 bits] [Hybrid] [12.5 MK/s] [150 MC/s] [Checkpoints: 12] [Found: 0]`

- **MK/s (Keys/s)**: Real progress in the bit range.
- **MC/s (Checks/s)**: Raw hashing power (includes compression and endomorphism multipliers).
- **Checkpoints**: Number of times the progress has been saved.

## 💾 Saving and Resuming

Bchaves automatically saves progress in a `.ckp` file (e.g., `address_hybrid_65.ckp`). 
- **To Stop**: Press `Ctrl+C`. The engine will save the final state.
- **To Resume**: Simply run the exact same command again. The engine will detect the checkpoint and resume from where it left off.
